# Identify-the-Filter — Answer Key
For `filter-response-unlabelled-1.svg` .. `-8.svg`. Reference only for Docs/quiz authoring — not published as a page.

| Plot | Answer | Tell |
|---|---|---|
| 1 | steep low-pass | Flat, falls sharply — one transition, steep skirt |
| 2 | gentle low-pass | Flat, falls gradually — one transition, shallow skirt |
| 3 | high-pass | Rises then flat — one transition, rising edge |
| 4 | narrow band-pass | Narrow hump — passband much narrower than the swept range |
| 5 | wide band-pass | Broad hump — wide passband, gentle sides |
| 6 | narrow deep notch | Narrow deep dip in an otherwise flat, high response |
| 7 | wide shallow notch | Wider, shallower dip — still a dip, not a hump |
| 8 | gentle high-pass | Rises then flat, shallow skirt — easy to mistake for flat/noisy without one |
