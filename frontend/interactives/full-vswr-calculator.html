Formulae
|Γ| = √(P_ref / P_fwd) = (V_max − V_min) / (V_max + V_min) = |(Z_L − Z_0) / (Z_L + Z_0)|
VSWR = (1 + |Γ|) / (1 − |Γ|)
RL = −20 log₁₀(|Γ|) [dB]
ML = −10 log₁₀(1 − |Γ|²) [dB]
P_del = P_fwd × (1 − |Γ|²)
