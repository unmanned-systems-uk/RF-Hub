## 2. About section (full channel description — under 1000 chars)

The "About" tab. YouTube uses first ~150 chars in search snippets.

```
RF-Hub is a free study and reference platform for UK amateur radio — Foundation, Intermediate, Full, and Direct-to-Full — with a growing knowledge base covering all things RF.

On this channel:
• Study-topic explainers matched to the RSGB syllabus (2024 Ofcom framework)
• Walk-throughs of the free interactive tools on rf-hub.info — VSWR, SWR animator, ATU matcher, MUF/LUF predictor, EMF calculator, callsign parser, and more
• Deep-dive episodes on measurement, propagation, antennas, and station work
• RF-Hub Radio podcast episodes in video form

Every video pairs with a full written study page on the site — visit rf-hub.info to read, practise with mock exams, and track your progress across sections.

RF-Hub is independent (not affiliated with RSGB or Ofcom), free to use, and updated continuously.

New here? Start at rf-hub.info/pages/study/ and pick your level.

73 — Study on.
```

**Character count:** ~950 chars (within 1000).

## Where each snippet goes in YouTube Studio

| Snippet | Location in YouTube Studio |
|---------|---------------------------|
| Tagline (#1) | Handle → "Description" field (short handle blurb) |
| About (#2) | Customization → About → "Channel description" |
| Keywords (#3) | Settings → Channel → Basic info → "Keywords" |
| Featured overlay (#4) | Customization → Layout → Featured section |
| Playlist copy (#5) | Content → Playlists → Edit playlist → Description |
| Channel banner | Customization → Branding → Banner image (needs separate design work) |
